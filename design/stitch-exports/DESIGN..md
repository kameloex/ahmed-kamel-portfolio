## Brand & Style

This design system expresses the discipline of computational engineering paired with high-end editorial curation. Designed for Ahmed Kamel, a developer specializing in Web & Interactive Systems based in Alexandria, Egypt, the aesthetic departs from standard portfolio templates by treating the digital interface as a precision instrument and high-fidelity architectural blueprinted workspace.

### Core Persona & Values
- **Engineered Rigor:** Mathematical structure, clean spatial alignment, precise hairline delineations, and explicit visual metadata (such as geographic markers, active coordinates, runtime parameters, and live system latency).
- **Subdued Luxury & Deep Space:** Grounded in an obsidian base, the environment feels serene, focused, and deliberate—refusing gratuitous neon glows in favor of restrained, crisp luminescence.
- **Mediterranean Cartography Meets Modern Systems Architecture:** Subtle typographic hints, telemetry motifs, and maritime/astronomical navigational cues nod to Alexandria's legacy as an intellectual center of cartography and science, rendered strictly through contemporary code and interaction.

### Visual Style Direction
The primary style merges **Engineered Precision** with **Minimalist High-Contrast Structure**:
- Micro-delimiters, subtle technical coordinates (`31.2001° N, 29.9187° E`), and hairline boundaries replace soft elevation layers.
- Interactivity is rapid, tactile, and predictable, featuring subtle light shifts and razor-sharp border transitions on hover and focus.

## Colors

The palette relies on absolute darkness, intermediate atmospheric planes, and surgical light accents to establish visual hierarchies.

### Color Hierarchy
- **Canvas Base (`#080B10`):** Obsidian void background. Absorptive, minimizing visual fatigue while providing deep contrast.
- **Surface Elevation (`#111923`):** Deep muted surface slate. Houses project containers, code execution blocks, telemetry chips, and interface panels.
- **Subtle Surface Inset (`#0D131B`):** Recessed containers, table headers, and sunken input wells.
- **Accent Primary (`#77CFFF`):** Crisp ice blue. Reserved exclusively for interactive prompts, key callouts, active system states, links, and focal data metrics.
- **Accent Muted (`#9AAEBC`):** Technical blue-gray. Used for structural metadata, secondary captions, subheadings, coordinate tags, and low-priority iconography.
- **High-Contrast Text (`#F5F7FA`):** Near-white, neutral balance. Ensures readability across displays without the optical glare of pure `#FFFFFF`.
- **Structural Borders (`#1A2430`):** Hairline edge boundary for panels, structural dividers, and card borders.
- **Interactive Border Highlight (`#2A3D52`):** Elevated border state triggered on card focus and hover.

## Typography

Typography balances technical identity with editorial reading comfort.

- **Headlines & Display:** Set in **Space Grotesk**. Its technical geometry, angular apexes, and idiosyncratic glyph treatments deliver a distinctive engineered tone. Tight negative letter-spacing keeps it compact and assertive.
- **Body & Longform:** Set in **Inter**. Neutral, highly legible at micro-scales, and optically balanced to offset the sharp personality of Space Grotesk.
- **Labels, Telemetry, and Metadata:** Set in **Space Grotesk** (and monospaced where tabular alignment is required), utilizing uppercase styling with wide tracking (`0.06em` to `0.08em`) to mimic instrumentation readouts, geographic coordinates, and industrial indices.
- **Code:** Fall back to **JetBrains Mono** for embedded code snippets, interactive terminal prompts, and architectural schema details.

## Layout & Spacing

The layout model is driven by an architectural grid structure. It rejects arbitrary whitespace in favor of systematic geometric rhythm.

### Grid Framework
- **Desktop (>= 1200px):** 12-column layout, max-width `1340px`, centered with explicit outer margins (`3rem`). Gutters set to `1.5rem`. Hairline vertical guide markers can run parallel along columns to echo architectural drafting paper.
- **Tablet (768px - 1199px):** 8-column layout, adaptive margins (`2rem`), gutters `1.25rem`.
- **Mobile (< 768px):** 4-column layout, fluid margins (`1.25rem`), gutters `1rem`.

### Spatial Flow
- Components use modular padding multiples of `0.25rem` (4px basis).
- Major case study sections and interactive demo sandboxes use expanded separation (`space-xl` combined with sectional horizontal rules) to create an intentional, curated tempo.

## Elevation & Depth

Visual depth is achieved through **Tonal Stacking and Low-Contrast Outlines**, avoiding standard blur-heavy drop shadows.

### Depth Paradigm
1. **Canvas Surface (0mm):** `#080B10` — The foundational viewport.
2. **Structural Plane (1mm):** `#111923` with a 1px solid border of `#1A2430`. Used for case study dossiers, experience cards, and code monitors.
3. **Floating Overlays & Menus (2mm):** `#0D131B` at 90% opacity with `backdrop-filter: blur(12px)` and a crisp 1px border of `#2A3D52`.
4. **Active/Hover Highlights:** Elevated panels do not jump upward in standard 3D space; instead, the border color shifts from `#1A2430` to `#77CFFF` (at 40% opacity), accompanied by an ultra-subtle, sharp ambient glow: `box-shadow: 0 0 20px rgba(119, 207, 255, 0.05)`.

## Shapes

The shape vocabulary uses clean, restrained geometry.

- **Base Radius:** `0.25rem` (4px). Standardized across inputs, standard cards, contextual badges, and action triggers.
- **Large Radius (`rounded-lg`):** `0.5rem` (8px). Reserved for macro viewports, hero code sandboxes, and major case study containers.
- **Micro Radius / Technical Badges:** `2px` to emphasize industrial machining.
- **Pill or Circular Shapes:** Avoided entirely, except for interactive status indicators (e.g., active telemetry pulsing dot). Buttons and tags remain structured rectangles with softened micro-radii to maintain an engineered aesthetic.

## Components

### Buttons & Interactive Triggers
- **Primary Action:** Solid Ice Blue background (`#77CFFF`) with obsidian typography (`#080B10`), font weight `600`, radius `4px`. On hover: border expands with a micro-glow; background shifts slightly to `#A5E0FF`.
- **Secondary Action:** Outlined style with `#1A2430` border, surface background `#111923`, text `#F5F7FA`. On hover: border transitions to `#77CFFF` and text color brightens.
- **Ghost/Coordinate Action:** Text-only, preceded by a monospaced crosshair `+` or coordinate symbol.

### Technical Tags & Chips
- **Coordinate & Status Badges:** Upper-case `label-sm` Space Grotesk. Enclosed in a 1px border (`#1A2430`) with `#0D131B` background. Includes a left-aligned micro status indicator: green for production systems, ice-blue for active experiments. Example: `LOC: 31.2001° N / SYS: ACTIVE`.

### Project & System Dossier Cards
- **Structure:** Encased in `#111923` with 1px `#1A2430` perimeter. Inner padding uses `1.5rem`.
- **Header:** Features an index number (`01`, `02`) in muted blue-gray (`#9AAEBC`), paired with the project title in Space Grotesk and a categorical tag.
- **Hover Behavior:** Card border transitions cleanly to `#2A3D52`; the project index shifts color to `#77CFFF`.

### Form Fields & Inputs
- **Base Style:** Recessed background (`#0D131B`), 1px border (`#1A2430`), text `#F5F7FA`, placeholder text `#9AAEBC` (reduced to 50% opacity).
- **Focus State:** 1px crisp outline in `#77CFFF`. No heavy diffuse outline rings.
- **Labels:** Positioned outside above the field, formatted in `label-sm` uppercase.

### Code & Terminal Inspector
- **Architecture:** Embedded shell blocks wrapped in `#0A0E14` with a minimal top bar showing filename and execution status.
- **Typography:** JetBrains Mono at `0.8125rem` with subdued syntax highlighting using variants of Ice Blue, Slate Gray, and Muted Teal.
